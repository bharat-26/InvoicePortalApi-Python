# Invoice Portal API — Student Starter

This repository is intentionally provided as a starter skeleton.

## Already prepared
- FastAPI project structure
- Supabase PostgreSQL / SQLAlchemy database configuration
- Environment-based application settings
- Dependency list
- Router folder structure

## You implement
- API endpoints and HTTP methods
- SQLAlchemy models
- Pydantic request/response schemas
- Authentication and authorization
- Password handling / JWT logic
- Validation and business logic
- Error handling
- Dashboard/invoice/customer functionality
- Router registration in `app/main.py`

## Setup
1. Create/use your Supabase PostgreSQL database.
2. Put your own Supabase connection string in `.env`.
3. Create a virtual environment.
4. Install dependencies from `requirements.txt`.
5. Implement the empty files.
6. Run the FastAPI application.

**Important:** Do not commit `.env` or real credentials to Git.
